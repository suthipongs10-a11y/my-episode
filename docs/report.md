# โครงสร้างรายงาน PDF (M5)

| หน้า | เนื้อหา |
|---|---|
| 1 | **ตัวเลข 3 ตัว ห้ามใส่อย่างอื่น** — เรา vs คู่แข่งอันดับ 1: `ติดหน้าแรก X/30 คำ` · `รีวิว Google X` · `หน้าบริการ X หน้า` |
| 2 | **"ทำไมเว็บไซต์ของคุณยังไม่มีลูกค้า"** — 3 สาเหตุจาก findings severity สูงสุด ภาษาชาวบ้าน ห้ามศัพท์ SEO |
| 3 | ตารางเทียบคู่แข่ง (เรา vs 3 ราย ช่องที่แพ้เป็นสีแดง) |
| 4 | Rank Grid Map (ตารางสีเขียว-เหลือง-แดง) |
| 5 | 5 สิ่งที่ควรทำก่อน — ทำอะไร / ทำไม / ใช้เวลาเท่าไร / คาดว่าดีขึ้นอย่างไร |
| 6 | รายการตรวจทั้งหมด จัดตาม severity |
| 7 | ข้อเสนอของเรา (static template + ช่องทางติดต่อ) |

ทุกหน้า footer: วันที่ audit · โดเมน · "รายงานนี้เป็นการวิเคราะห์จากข้อมูลสาธารณะ ไม่ใช่การรับประกันอันดับ"

## ฟอนต์ไทย — ทดสอบตั้งแต่เนิ่น ๆ

ต้อง **embed ไฟล์ TTF ผ่าน `@font-face`** ห้ามพึ่งฟอนต์ระบบ
โดยเฉพาะใน Docker ที่ไม่มีฟอนต์ไทยติดมาด้วย เรื่องนี้พังบ่อยและมักพังตอนใกล้เสร็จ
