## สิ่งที่ต้องทำ
เสนอคำค้นหาเพิ่มไม่เกิน {{limit}} คำ ที่ **คนไทยพิมพ์จริง** เวลาจะซื้อหรือจ้างบริการนี้
เน้นคำที่มีเจตนาจะจ้าง/ซื้อ (transactional) มากกว่าคำที่แค่หาความรู้

กติกา:
- ภาษาไทยเป็นหลัก ใส่คำภาษาอังกฤษได้ถ้าคนไทยพิมพ์แบบนั้นจริง
- ใส่ชื่อพื้นที่ต่อท้ายได้ ถ้าเป็นคำที่คนค้นแบบเจาะพื้นที่
- ห้ามเสนอชื่อแบรนด์คู่แข่ง
- ห้ามเสนอคำที่ไม่เกี่ยวกับธุรกิจนี้

**สำคัญที่สุด: ห้ามใส่ตัวเลขใด ๆ** ไม่ว่าจะเป็นปริมาณการค้นหา ความยาก อันดับ หรือคะแนน
ระบบมีข้อมูลตัวเลขจริงอยู่แล้วและจะไม่ใช้ตัวเลขจากคุณ ถ้าคุณเดาตัวเลขมามันจะถูกทิ้ง

## รูปแบบคำตอบ
ตอบเป็น JSON เท่านั้น ห้ามมีข้อความอื่นนอก JSON

```json
{
  "keywords": [
    { "term": "คำค้นหา", "intent": "transactional" }
  ]
}
```

`intent` ต้องเป็นหนึ่งใน: `transactional` (พร้อมจ้าง/ซื้อ) ·
`informational` (หาความรู้) · `navigational` (หาแบรนด์หรือเว็บใดเว็บหนึ่ง)
