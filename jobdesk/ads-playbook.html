Ads 990

วิธีใช้ Facebook Ads ให้ได้กำไรที่ราคาขาย 990 บาท เมื่อโฆษณาเป็นช่องทางหาลูกค้าช่องทางเดียว

เอกสารนี้คู่กับแบบร่างระบบ JobDesk — อันนั้นคือสิ่งที่ต้องสร้าง อันนี้คือวิธีใช้เงินโฆษณา ทุกตัวเลขในนี้ผูกกับเศรษฐศาสตร์ของงาน 990 ถ้าราคาเปลี่ยน ต้องคำนวณใหม่ทั้งหมด

ข้อจำกัดที่กำหนดทุกอย่าง: โฆษณาเป็นช่องทางเดียว แปลว่าค่าโฆษณาไม่ใช่ค่าการตลาด แต่เป็นต้นทุนขายโดยตรง ไม่มีงบ “สร้างแบรนด์” ให้เล่น และราคา 990 แคบเกินกว่าจะจ้างเอเจนซี่ ถ่ายโปรดักชัน หรือทดสอบยาว ๆ ยี่สิบชุด

สิ่งที่ทำได้และรายใหญ่ทำไม่ได้: ตอบเร็ว ปิดเก่ง และรู้ว่าลูกค้าคนไหนจ่ายเงินจริง ทั้งเอกสารสร้างรอบสามอย่างนี้

เพิ่มอัตราปิดฟรี ลด CPL ต้องจ่ายด้วยงบหรือเวลา §4 จึงเป็นบทที่สำคัญที่สุดในเอกสารนี้ ไม่ใช่บทเรื่องครีเอทีฟ

§2

ความจริงเรื่องงบที่ต้องรู้ก่อนวางแผน

Meta ต้องการ ประมาณ 50 ผลลัพธ์ต่อสัปดาห์ต่อ ad set เพื่อออกจาก learning phase (ราว 7 ต่อวัน) ก่อนหน้านั้นระบบยังเดาอยู่ ค่าต่อผลลัพธ์จะแพงและแกว่ง

ไม่ใช่หายนะ โฆษณายังยิงและยังได้ลูกค้า แต่มีผลตามมาสามข้อที่ต้องยอมรับ:

1 · ห้ามแตกงบเด็ดขาด

ad set เดียว ทุกบาทไปที่เดียวกัน แตกเป็น 3 ชุด ชุดละ 33 ฿/วัน = ไม่มีชุดไหนได้เรียนรู้เลยสักชุด

2 · อย่าตกใจกับรายวัน

วันที่ได้ 0 คนทักไม่ได้แปลว่าพัง ดูเป็นรายสัปดาห์เท่านั้น

3 · ขยายที่ชุดเดิม

ถ้าจะเพิ่มงบ ให้ใส่เพิ่มที่ ad set เดิม ไม่ใช่เปิดชุดใหม่

โครงสร้างที่ควรเป็น

1 แคมเปญ · วัตถุประสงค์: ข้อความ (Messaging) └─ 1 ad set · optimize: เริ่มบทสนทนา ├─ ครีเอทีฟ A ├─ ครีเอทีฟ B └─ ครีเอทีฟ C ← ให้ Meta เลือกเอง อย่าแยก ad set

ทำไมต้อง Messaging ไม่ใช่ Conversion — ที่ปริมาณนี้ ถ้า optimize เป็น “ซื้อ” จะได้ผลลัพธ์ราว 5 ครั้ง/สัปดาห์ ห่างจาก 50 มาก จะไม่มีวันออกจาก learning phase เลยตลอดชีพ ส่วน “คนทัก” เกิดบ่อยกว่ามาก จึงเป็นเหตุการณ์เดียวที่มีจำนวนพอให้ระบบเรียนรู้ได้

กลุ่มเป้าหมายตั้งกว้างไว้ — ไทย อายุ 25–55 ไม่ต้องใส่ interest อะไรเลย การไล่ใส่ interest ละเอียด ๆ เป็นวิธีคิดของปี 2018 ทุกวันนี้ระบบหาคนที่จะทักเก่งกว่าการเดาของเรา และการจำกัดกลุ่มแคบทำให้ค่าต่อผลลัพธ์แพงขึ้นเฉย ๆ

§3

Facebook รู้แค่ครึ่งเดียว

ผลที่ตามมาซึ่งอันตรายมาก: Meta จะ optimize ไปหาคนที่ทักง่ายที่สุด ไม่ใช่คนที่จ่ายเงิน แคมเปญที่ได้คนทักถูก ๆ จากคนที่ถามเล่นจะดูดีที่สุดใน Ads Manager และขาดทุนจริง

ตัวเลขดูที่ไหนใช้ตัดสินอะไร

§4

ข้อความแรกที่ตอบลูกค้า — บทที่สำคัญที่สุด

§1 พิสูจน์แล้วว่าอัตราปิดการขายเป็นตัวคูณที่แรงกว่าทุกอย่าง และมันถูกตัดสิน ในข้อความแรกที่ตอบกลับ ไม่ใช่ในโฆษณา

ตอบภายใน 5 นาที ตอนที่เขายังเปิดแอปอยู่และยังคิดเรื่องนี้อยู่ ตอบพรุ่งนี้เช้าคือคุยกับคนที่ทักไปอีกสามเจ้าแล้ว ตั้งข้อความอัตโนมัติของเพจไว้ซื้อเวลา แล้วไปตอบจริงภายในไม่กี่นาที

ไม่ต้องรอให้เขาถามราคา บอกไปเลย คนที่รับราคาไม่ได้จะหายไปตั้งแต่นาทีแรก ซึ่งเป็นเรื่องดี — เวลาที่ประหยัดได้คือกำไร

สวัสดีครับ ขอบคุณที่ทักมาครับ 🙏 ทำเว็บให้ธุรกิจอะไรครับ เดี๋ยวผมส่งตัวอย่างที่ใกล้เคียงให้ดู ราคา 990 บาท ได้ [จำนวน] หน้า พร้อม [สิ่งที่รวม] เสร็จภายใน [X] วัน แก้ได้ [Y] รอบ ตัวอย่างงานที่เคยทำ: 1. … 2. … 3. … สนใจให้เริ่มเลยไหมครับ ผมขอข้อมูลร้านนิดหน่อย

จุดสำคัญสี่อย่าง: ถามว่าธุรกิจอะไร (ทำให้เขาตอบ) · บอกราคาทันที · ส่งตัวอย่างจริง · ปิดด้วยคำถามที่ตอบง่าย

JobDesk บันทึกทุกคนที่ทักมาและเหตุผลที่ไม่ซื้อ ถ้าเหตุผล “แพงไป” ขึ้นมาเกินครึ่ง แปลว่าโฆษณาดึงคนผิดกลุ่ม ไม่ใช่ราคาผิด — ต้องแก้ที่โฆษณาให้พูดราคาชัดขึ้น ไม่ใช่ลดราคา

§5

ครีเอทีฟ

ลำดับการทดสอบ เรียงตามผลกระทบ

คนส่วนใหญ่ทดสอบจากล่างขึ้นบน ซึ่งกลับหัว:

  1. ข้อเสนอ — ราคา สิ่งที่รวม เงื่อนไข เปลี่ยนผลลัพธ์มากที่สุด
  2. hook สามบรรทัดแรก — คนตัดสินใจหยุดนิ้วตรงนี้
  3. ภาพหรือวิดีโอ
  4. กลุ่มเป้าหมาย — เปลี่ยนน้อยที่สุด ปล่อยให้ Meta ทำ

รูปแบบที่ทำเองได้ใน 30 นาที

  • ภาพหน้าจอเว็บที่เคยทำ วางเรียง 3–4 อัน ใส่ราคาทับ — ง่ายที่สุด พิสูจน์ผลงานได้ทันที
  • ก่อน/หลัง เพจเฟซบุ๊กรก ๆ เทียบกับเว็บที่เป็นระเบียบ
  • วิดีโอจอ 15–20 วินาที เลื่อนเว็บที่ทำเสร็จให้ดู ถ่ายจากมือถือได้เลย
  • ข้อความตรง ๆ บนพื้นสีเดียว ราคาและสิ่งที่ได้ ไม่ต้องมีรูป

หลีกเลี่ยง: ภาพสต็อกฝรั่งใส่สูท ข้อความยาวเป็นเรียงความ และคำว่า “โปรโมชั่นพิเศษ” ลอย ๆ

เปลี่ยนครีเอทีฟเมื่อไหร่

  • Frequency เกิน 2.5 — คนกลุ่มเดิมเห็นซ้ำจนเบื่อแล้ว
  • CPL ขึ้นเกิน 50% จากค่าเฉลี่ย 7 วันก่อนหน้า และไม่ลงกลับใน 3 วัน
  • ผ่านไป 4–6 สัปดาห์ ต่อให้ตัวเลขยังดี

เตรียมครีเอทีฟสำรองไว้ 2 ชิ้นเสมอ วันที่ตัวหลักตกคือวันที่ต้องมีของเปลี่ยนทันที ไม่ใช่วันที่เพิ่งเริ่มคิด

§6

วิเคราะห์คู่แข่ง

เปิด facebook.com/ads/library เลือกประเทศไทย ไม่ต้องล็อกอิน ค้นชื่อเพจคู่แข่ง หรือคำว่า “รับทำเว็บ” “ทำเว็บไซต์” “เว็บร้านค้า” — ฟรีและพอแล้ว

สัญญาณเดียวที่เป็นของจริง คือ อายุของโฆษณา

Ad Library ไม่แสดงผลลัพธ์ของใครทั้งนั้น ไม่มี CTR ไม่มี ROAS ไม่มียอดขาย ใครขายเครื่องมือที่อ้างว่าดูตัวเลขคู่แข่งได้ นั่นคือการประมาณให้ฟัง

แต่ โฆษณาที่ยิงตัวเดิมมาหลายเดือนแล้วยังทำงานอยู่ = โฆษณาที่ทำเงินให้เขา ไม่มีใครจ่ายเงินยิงของที่ขาดทุนต่อเนื่องสามเดือน นั่นคือสูตรที่ผ่านการทดสอบด้วยเงินจริงของคนอื่นมาแล้ว

จดทุกครั้งเพราะ
ชื่อเพจไว้ตามต่อ
วันที่เริ่มยิงอายุ = สัญญาณเดียวที่บอกว่าได้ผล
ราคาที่โฆษณาบอกว่าตลาดอยู่ตรงไหน เราถูกหรือแพงเกิน
สิ่งที่สัญญาจำนวนหน้า ฟรีโดเมนไหม กี่วันเสร็จ กี่รอบแก้
hook สามบรรทัดแรกสิ่งที่เอามาปรับใช้ได้เร็วที่สุด
จำนวนตัวที่ยิงพร้อมกันบอกว่าเขาลงทุนหนักแค่ไหน

ทำเดือนละครั้ง 20 นาที ไม่ต้องบ่อยกว่านี้ ตลาดไม่ได้เปลี่ยนทุกสัปดาห์ และเวลาที่เอาไปส่องคู่แข่งคือเวลาที่ไม่ได้เอาไปตอบลูกค้า

ห้ามลอกทั้งดุ้น ราคาที่เขาโฆษณาอาจมาพร้อมต้นทุนที่เราไม่เห็น (ทีมงาน 5 คน หรือขายของเสริมทีหลัง) เอามาเป็นข้อมูล ไม่ใช่เอามาเป็นคำสั่ง

§7

กฎการตัดสินใจ

ตัวเลขข้างล่างคิดจากเพดาน CAC 300 และ CPL เป้า 60 บาท (อัตราปิด 20%) ถ้าอัตราปิดจริงของคุณต่างจากนี้ ให้คำนวณเพดาน CPL ใหม่จาก §1 ก่อน

สถานการณ์ทำอะไร
ใช้งบไป 180 ฿ (3× CPL เป้า) ยังไม่มีใครทักฆ่าครีเอทีฟตัวนั้น
CPL > 90 ฿ หลังใช้ไป 300 ฿ฆ่าหรือรื้อครีเอทีฟใหม่
CPL 60–90 ฿ปล่อยไว้ ดูอีกสัปดาห์ อย่าเพิ่งขยับ
CPL < 60 และอัตราปิด ≥ 15%ขยายงบ +20–30% ต่อครั้ง ห่างกันอย่างน้อย 3 วัน
CAC > 300 สองสัปดาห์ติดหยุดยิง กลับไปแก้ §4 ก่อน ไม่ใช่แก้โฆษณา
Frequency > 2.5เปลี่ยนครีเอทีฟ
ยังไม่ถึง 3 วัน หรือใช้ไม่ถึง 3× CPL เป้าห้ามแตะ

ห้ามตัดสินก่อน 3 วัน

ระบบยังเรียนรู้อยู่ ตัวเลขวันแรกไม่มีความหมาย

ห้ามขยับงบเกิน 30%

การขยับแรง ๆ ทำให้ ad set กลับเข้า learning phase และเสียการเรียนรู้ที่ลงทุนไปแล้วทั้งหมด

ห้ามปิดแล้วเปิดใหม่

ทุกครั้งที่เปิดใหม่คือเริ่มนับ learning ใหม่ ถ้าจะหยุดให้หยุดยาว

§8

ทุกวัน · 5 นาที

ทุกสัปดาห์ · 20 นาที

นำเข้าค่าโฆษณา CSV เข้า JobDesk · ดู CPL / อัตราปิด / CAC · ใช้กฎใน §7 ตัดสิน · เช็ก Frequency

§9

สิ่งที่ JobDesk ต้องมีเพิ่ม

เฟส 4 ตามแผนเดิมครอบคลุมส่วนใหญ่แล้ว — คนที่ทักมา แคมเปญ ค่าโฆษณารายวัน หน้าโฆษณาที่คำนวณ CPL / CAC / อัตราปิด และเตือนเมื่อทะลุเพดาน เอกสารนี้เพิ่มสามอย่าง:

บันทึกครีเอทีฟ

ครีเอทีฟไหนเริ่มวันไหน หยุดวันไหน — เพื่อตอบได้ว่า CPL ที่พุ่งสัปดาห์ที่แล้ว ตรงกับวันเปลี่ยนครีเอทีฟพอดีไหม ถ้าไม่บันทึกจะเดาตลอดไป

บันทึกคู่แข่ง

ที่เก็บผลส่อง Ad Library รายเดือน ค่าของมันอยู่ที่การเปรียบเทียบข้ามเดือน — ตัวไหนของเขายังอยู่หลังสามเดือน ซึ่งการส่องครั้งเดียวไม่มีวันบอกได้

เพดาน CAC ที่แก้ได้จากหน้าเว็บ

ตอนนี้อยู่ใน .env ควรแก้ได้จากหน้าเว็บ เพราะ §8 บอกให้ทบทวนทุกเดือน

§10

สิ่งที่ห้ามทำ เรียงตามความเสียหาย

  1. แตกงบไปหลาย ad set — ไม่มีชุดไหนพ้น learning phase ทั้งเดือนคือการจ่ายค่าเรียนรู้ที่ไม่มีวันได้ใช้
  2. optimize เป็น purchase — ที่ปริมาณ 5 งาน/สัปดาห์ จะไม่มีวันพ้น learning
  3. ตัดสินด้วย ROAS ใน Ads Manager — มันไม่รู้ว่าใครจ่ายเงินจริง
  4. ปิด ๆ เปิด ๆ หรือขยับงบแรง ๆ — รีเซ็ต learning ทุกครั้ง
  5. จ้างเอเจนซี่หรือซื้อเครื่องมือแพง ๆ — ที่กำไร 770 ฿/งาน ค่าบริการเดือนละ 3,000 คือต้องขายเพิ่ม 4 งานเพื่อเสมอตัว
  6. ลดราคาเพราะปิดไม่ได้ — ปัญหามักอยู่ที่ข้อความแรก (§4) และการลดราคาทำให้เพดาน CAC แคบลงอีก ทุกอย่างยากขึ้น ไม่ใช่ง่ายขึ้น
  7. ไล่ใส่ interest ละเอียด ๆ — แพงขึ้นโดยไม่ได้อะไร
§11

ทำอะไรก่อนหลัง

สัปดาห์นี้ ข้อที่ 1 สำคัญที่สุดและใช้เวลา 5 นาที — ใส่ ?ref=camp_xxx ในลิงก์โฆษณาทุกตัว ไม่ทำวันนี้ = ข้อมูลของเดือนนี้หายถาวร และจะไม่มีวันรู้ย้อนหลังว่า ลูกค้าที่จ่ายเงินมาจากแคมเปญไหน

  1. ใส่ m.me/<เพจ>?ref=camp_xxx ในลิงก์โฆษณาทุกตัว
  2. รวม ad set ให้เหลือชุดเดียว
  3. เขียนข้อความแรกตาม §4 แล้วตั้งข้อความอัตโนมัติของเพจ
  4. ส่อง Ad Library หนึ่งรอบ จดตาม §6
  5. บันทึกทุกคนที่ทักลง JobDesk ให้ครบ — ตัวหารของอัตราปิดมาจากตรงนี้
  6. นำเข้าค่าโฆษณา CSV รายสัปดาห์
  7. หา CPL และอัตราปิดจริงของตัวเอง แล้วคำนวณเพดานใน §1 ใหม่จากตัวเลขจริง

แล้วค่อยทำเฟส 4 — เมื่อมีตัวเลขจริงสองเดือนแล้ว เกณฑ์ที่ตั้งจะเป็นของจริง ไม่ใช่ของที่สมมติไว้ในเอกสารนี้
