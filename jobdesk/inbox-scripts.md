## §0 ก่อนอื่น — เติมช่องว่าง 7 ช่องนี้ให้ครบก่อน

ทุกข้อความข้างล่างมีวงเล็บเหลี่ยมอยู่ เติมครั้งเดียวแล้วใช้ได้ทั้งเอกสาร

| ช่อง | ใส่อะไร | หมายเหตุ |
|---|---|---|
| `[n หน้า]` | เว็บ 1,990 ได้กี่หน้า | ถ้าไม่เคยกำหนด ให้กำหนดวันนี้ |
| `[รวมอะไร]` | โดเมนรวมไหม · โฮสต์รวมกี่ปี | **ช่องที่ทำให้ทะเลาะกันบ่อยที่สุดถ้าไม่พูดตั้งแต่แรก** |
| `[X วัน]` | เสร็จภายในกี่วัน | นับจากวันที่ได้ข้อมูลครบ ไม่ใช่วันที่โอนมัดจำ |
| `[Y รอบ]` | แก้ได้กี่รอบ | ค่าตั้งต้นในระบบคือ 2 |
| `[ค่าต่ออายุ]` | ปีต่อไปจ่ายเท่าไหร่ | เอกสารระบบแนะนำ 990/ปี |
| `[มัดจำ]` | มัดจำเท่าไหร่ จ่ายยังไง | |
| `[ตัวอย่าง 1-3]` | ลิงก์ผลงาน 3 อัน | ให้เป็นคนละประเภทธุรกิจ จะได้เลือกส่งให้ตรง |

> **ห้ามส่งข้อความที่ยังมีวงเล็บเหลี่ยมค้างอยู่** อ่านทวนหนึ่งรอบก่อนกดส่งเสมอ

## §1 ข้อความไหนไปอยู่ตรงไหนใน Meta Business Suite

Business Suite ทำให้อัตโนมัติได้ไม่เยอะเท่าที่คนคิด รู้ขอบเขตก่อนจะได้ไม่เสียเวลา

| ชั้น | ที่ตั้งค่า | ได้กี่ข้อความ | ใช้กับอะไร |
|---|---|---|---|
| **1. ตอบกลับทันที** | กล่องข้อความ → การตอบกลับอัตโนมัติ | **1 ข้อความเท่านั้น** | §2 |
| **2. คำถามที่พบบ่อย** | ที่เดียวกัน | ปุ่มไม่กี่ปุ่ม (ราว 4) | §5 — เลือก 4 ข้อ |
| **3. ข้อความที่บันทึกไว้** | กล่องข้อความ → ข้อความที่บันทึกไว้ | ไม่จำกัด แต่ต้องกดเองทุกครั้ง | §3–§7 ที่เหลือทั้งหมด |

**ชั้น 3 คือของจริง** สิ่งที่ปิดการขายคือคนตอบ ไม่ใช่ระบบตอบ

> จำนวนปุ่มคำถามที่พบบ่อยเปลี่ยนตามเวอร์ชัน เปิดดูของจริงในเพจตัวเองก่อนจัดลำดับ

## §2 ข้อความแรก — ตัวเดียวที่เป็นอัตโนมัติ

ทำสามอย่างพร้อมกัน: ซื้อเวลา · บอกราคา · เปิดคำถามแรก

```
สวัสดีครับ ขอบคุณที่ทักมานะครับ 🙏

ผมรับทำเว็บไซต์ธุรกิจ 2 ภาษา ไทย–อังกฤษ ราคา 1,990 บาท
[รวมอะไร] เสร็จภายใน [X วัน]

ขอถามก่อนนะครับ ทำธุรกิจอะไรอยู่ครับ
เดี๋ยวผมส่งตัวอย่างเว็บของธุรกิจแบบเดียวกันให้ดูเลยครับ
```

**ทำไมบอกราคาตั้งแต่บรรทัดแรก** คนที่รับราคาไม่ได้จะหายไปตั้งแต่นาทีแรก
ซึ่งเป็นเรื่องดี — `ads-playbook.md` §2 บอกว่าข้อจำกัดจริงของธุรกิจนี้คือ**เวลา ไม่ใช่เงิน**
เวลาที่ไม่ต้องคุยกับคนที่ไม่ซื้อคือกำไรโดยตรง

**ทำไมต้องมีคำว่า "2 ภาษา"** ถ้าไม่พูด เขาจะเอา 1,990 ไปเทียบกับเว็บภาษาเดียวราคา 990
แล้วรู้สึกว่าแพง ทั้งที่เราขายคนละของ

## §3 บันไดคำถาม 4 ขั้น

ขั้นละหนึ่งคำถาม ห้ามลัด ห้ามถามสองข้อในข้อความเดียว

| ขั้น | ถามอะไร | ได้อะไรกลับมา | ลงที่ไหนใน JobDesk |
|---|---|---|---|
| 1 | ทำธุรกิจอะไร | ประเภทธุรกิจ + รู้ว่าจะส่งตัวอย่างไหน | ลูกค้า → กิจการ |
| 2 | ตอนนี้มีอะไรอยู่แล้ว | เนื้อหามีแค่ไหน งานจะหนักแค่ไหน | งาน → รายละเอียด |
| 3 | **อยากให้เว็บเน้นอะไร** | โครงหน้าเว็บทั้งหมด | งาน → เช็กลิสต์ |
| 4 | เริ่มเลยไหม | ปิดการขาย | งาน → เปิดงาน |

### ขั้น 1 · เขาบอกว่าทำธุรกิจอะไร → ทวนกลับ + ส่งตัวอย่าง + ถามข้อต่อไป

**ทวนสิ่งที่เขาบอกกลับไปก่อนเสมอ** เป็นวิธีที่ถูกที่สุดที่ทำให้เขารู้ว่าคุยกับคน
ไม่ใช่ระบบ และเป็นจุดที่คนหายไปมากที่สุดถ้าไม่ทำ

**แบบ ก — ร้านอาหาร คาเฟ่ ร้านกาแฟ**
```
ร้านอาหารนี่เว็บสองภาษาช่วยได้เยอะเลยครับ
ลูกค้าต่างชาติเขาหาอยู่สองอย่าง คือเมนูกับราคา และที่ตั้งกับเวลาเปิด
ถ้าหาไม่เจอ เขาไปร้านถัดไปเลยครับ

ตัวอย่างที่ผมทำให้ร้านแบบเดียวกันครับ 👉 [ตัวอย่าง 1]

ตอนนี้ร้านมีอะไรอยู่แล้วบ้างครับ
1) มีแค่เพจเฟซบุ๊ก
2) มีเพจ + IG
3) เคยมีเว็บ แต่ไม่ได้ใช้แล้ว
4) ยังไม่มีอะไรเลย
```

**แบบ ข — ที่พัก ทัวร์ สปา คลินิก งานสายท่องเที่ยว**
```
งานสายท่องเที่ยวนี่ภาษาอังกฤษคือคนละตลาดเลยครับ
ลูกค้าต่างชาติหาข้อมูลก่อนบินมา ถ้าเจอแต่เพจภาษาไทยเขาข้ามไปเลย

ตัวอย่างที่ผมทำให้ธุรกิจแบบเดียวกันครับ 👉 [ตัวอย่าง 2]

ตอนนี้มีอะไรอยู่แล้วบ้างครับ
1) มีแค่เพจเฟซบุ๊ก
2) มีเพจ + IG
3) เคยมีเว็บ แต่ไม่ได้ใช้แล้ว
4) ยังไม่มีอะไรเลย
```

**แบบ ค — ร้านค้า บริการทั่วไป รับเหมา ขนส่ง**
```
เข้าใจแล้วครับ

เว็บช่วยสองจังหวะครับ ตอนลูกค้าเสิร์ชหาเอง กับตอนเราส่งลิงก์ให้ใครดู
ส่งลิงก์เว็บกับส่งลิงก์เพจ ความน่าเชื่อถือคนละเรื่องเลยครับ

ตัวอย่างงานที่ผมเคยทำครับ 👉 [ตัวอย่าง 3]

ตอนนี้มีอะไรอยู่แล้วบ้างครับ
1) มีแค่เพจเฟซบุ๊ก
2) มีเพจ + IG
3) เคยมีเว็บ แต่ไม่ได้ใช้แล้ว
4) ยังไม่มีอะไรเลย
```

### ขั้น 2 · เขาตอบว่ามีอะไรอยู่ → ถามข้อที่สำคัญที่สุด

นี่คือคำถามที่ทำให้เว็บของเขาไม่เหมือนของคนอื่น และเป็นคำถามที่ทำให้เขา
เริ่มนึกภาพเว็บตัวเองออก — คนที่นึกภาพออกแล้วจะไม่ค่อยหายไป

```
โอเคครับ 👍

อยากให้เว็บช่วยเรื่องไหนมากที่สุดครับ เลือกได้มากกว่า 1 ข้อครับ
1) ให้ลูกค้าโทร หรือทักไลน์ได้ง่าย ๆ
2) ให้ดูสินค้า–บริการ–ราคา ได้ครบ
3) ให้จองหรือสั่งล่วงหน้าได้
4) ให้ดูผลงาน รีวิว รูปจริง
5) ให้ดูน่าเชื่อถือ เวลาส่งลิงก์ให้ลูกค้าหรือคู่ค้า

ผมจะได้วางหน้าเว็บให้ตรงกับที่ร้านใช้จริงครับ ไม่ใช่ทำเป็นแบบสำเร็จรูป
```

### ขั้น 3 · สรุปให้เห็นภาพ แล้วค่อยปิด

อย่ากระโดดจากคำถามไปที่ "สนใจไหม" ให้เขาเห็นของก่อน

```
ได้เลยครับ แบบนี้ผมวางเป็น [n หน้า] ครับ

· หน้าแรก — [สิ่งที่เขาเลือกในขั้น 2] เห็นตั้งแต่จอแรก
· หน้า [สินค้า / บริการ / เมนู] พร้อมราคา
· หน้าติดต่อ + แผนที่ + ปุ่มโทรและไลน์

ทุกหน้ามีทั้งไทยและอังกฤษ กดสลับภาษาได้ทุกหน้าครับ

ราคา 1,990 บาท เสร็จภายใน [X วัน] แก้ได้ [Y รอบ]
[รวมอะไร]

สนใจให้เริ่มเลยไหมครับ ผมขอข้อมูลนิดหน่อยแล้วเริ่มได้เลย
```

### ขั้น 4 · เขาตกลง → ขอข้อมูลชุดเดียวจบ

```
ขอบคุณครับ 🙏 ขอข้อมูลชุดนี้ครับ พิมพ์มาในแชทได้เลย

1) ชื่อร้าน/ธุรกิจ ทั้งภาษาไทยและอังกฤษ (ถ้ามี)
2) ที่อยู่ และลิงก์ Google Maps
3) เบอร์โทร / ไลน์ / เพจ
4) เวลาทำการ
5) โลโก้ ถ้ามี และรูปสินค้า–รูปร้าน สัก 10–15 รูป

ส่งเท่าที่มีก่อนได้ครับ ที่เหลือทยอยส่งได้
[มัดจำ]

พอได้ข้อมูลครบ ผมจะส่งหน้าแรกให้ดูภายใน [X วัน] ครับ
```

> **นับ [X วัน] จากวันที่ได้ข้อมูลครบ ไม่ใช่วันที่โอนมัดจำ** และต้องพูดตรงนี้
> ไม่ใช่ไปพูดตอนงานเลยกำหนด

## §4 กฎ 6 ข้อที่ทำให้บทสนทนาไม่ตาย

1. **ถามครั้งละหนึ่งข้อ** ถามสองข้อพร้อมกัน เขาจะตอบข้อเดียว หรือไม่ตอบเลย
2. **ทุกข้อความจบด้วยคำถาม** ข้อความที่จบด้วยจุด คือจุดที่บทสนทนาตาย
3. **ให้เลือกเป็นตัวเลข** พิมพ์ "2" ง่ายกว่าพิมพ์ประโยค คนตอบเยอะขึ้นชัดเจน
4. **ทวนสิ่งที่เขาบอกก่อนตอบทุกครั้ง** "ร้านอาหารนี่…" ทำให้รู้ว่าเราอ่านจริง
5. **บอกราคาตั้งแต่ข้อความแรก** ไม่ต้องรอให้ถาม
6. **ตอบภายใน 5 นาที** ระบบอัตโนมัติซื้อเวลาให้ ไม่ได้ทำงานแทน

**ห้ามทำ**

- ส่งข้อความยาวเป็นพืด — บนมือถือมันคือกำแพง ไม่ใช่ข้อมูล
- ถาม 3 ข้อในข้อความเดียว
- ส่งแค่ลิงก์เปล่า ๆ ไม่มีข้อความ
- ลดราคาเองก่อนเขาต่อ
- สัญญาว่า "ติดหน้าแรก Google"
- ตอบว่า "ได้ครับ" เฉย ๆ แล้วรอให้เขาถามต่อ

## §5 คำถามที่พบบ่อย

### 4 ข้อที่ควรได้ปุ่มในคำถามที่พบบ่อย

เลือกจากคำถามที่ **ถ้าไม่ตอบแล้วเขาหายไปเลย** ไม่ใช่คำถามที่ถามบ่อยที่สุด

**1 · ราคาเท่าไหร่ รวมอะไรบ้าง**
```
เว็บไซต์ธุรกิจ 2 ภาษา ไทย–อังกฤษ ราคา 1,990 บาทครับ
ได้ [n หน้า] · [รวมอะไร] · เสร็จภายใน [X วัน] · แก้ได้ [Y รอบ]

ทำธุรกิจอะไรอยู่ครับ เดี๋ยวผมส่งตัวอย่างที่ใกล้เคียงให้ดูครับ
```

**2 · ใช้เวลากี่วัน**
```
[X วัน] ครับ นับจากวันที่ได้ข้อมูลร้านครบ
(ชื่อ ที่อยู่ เบอร์ เวลาทำการ รูปสินค้า)

ส่วนใหญ่ที่ช้าไม่ใช่ที่ผมทำ แต่รอรูปกับเนื้อหาจากทางร้านครับ
ถ้ามีรูปพร้อมอยู่แล้วจะเร็วกว่านี้

ตอนนี้มีรูปสินค้าหรือรูปร้านอยู่แล้วไหมครับ
```

**3 · ขอดูตัวอย่างผลงาน**
```
ได้เลยครับ 👇
[ตัวอย่าง 1]
[ตัวอย่าง 2]
[ตัวอย่าง 3]

ลองกดปุ่มสลับภาษามุมบนขวาดูได้ครับ จะเห็นว่าเปลี่ยนทั้งหน้า
ไม่ใช่แค่แปลเมนู

ทำธุรกิจอะไรอยู่ครับ ผมมีตัวอย่างที่ใกล้เคียงกว่านี้อีก
```

**4 · ปีต่อไปต้องจ่ายอะไรอีกไหม**
```
มีครับ และผมบอกตั้งแต่ตอนนี้เลยดีกว่าไปเซอร์ไพรส์ทีหลัง

ปีแรก [รวมอะไร]
ปีถัดไป [ค่าต่ออายุ] ครับ (ต่อโดเมน + โฮสต์ + ดูแลให้)
ถ้าไม่ต่อ เว็บจะปิดตัวเอง แต่ผมจะแจ้งล่วงหน้าก่อนหมดอายุครับ

มีคำถามอื่นอีกไหมครับ
```

### คำถามอื่นที่เจอบ่อย — เก็บเป็นข้อความที่บันทึกไว้

**โดเมนเป็นชื่อของใคร**
```
ของคุณครับ จดในชื่อร้าน/ชื่อคุณ ไม่ใช่ชื่อผม
ถ้าวันหนึ่งอยากย้ายไปให้คนอื่นดูแล ย้ายได้เลยครับ ผมส่งรหัสให้
```

**ใครแปลเป็นภาษาอังกฤษ**
```
ผมแปลให้ครับ รวมอยู่ในราคาแล้ว
ถ้าเป็นคำเฉพาะทาง เช่น ชื่อเมนู ชื่อบริการ ผมจะส่งกลับให้ตรวจก่อนขึ้นจริง

ตอนนี้มีเนื้อหาภาษาไทยพร้อมอยู่แล้วไหมครับ
```

**มีแต่เนื้อหาภาษาไทย ไม่มีอังกฤษเลย**
```
ไม่เป็นไรครับ ส่วนใหญ่เป็นแบบนี้กันหมด
ส่งภาษาไทยมาอย่างเดียวพอครับ ผมแปลและจัดหน้าให้ทั้งสองภาษา
แล้วส่งให้ตรวจก่อนขึ้นจริง

มีข้อความแนะนำร้านอยู่แล้วไหมครับ หรือให้ผมช่วยร่างให้
```

**แก้เนื้อหาเองได้ไหมทีหลัง**
```
ได้ครับ ผมทำเป็นระบบที่เข้าไปแก้ข้อความและเปลี่ยนรูปเองได้
ส่งวิธีใช้ให้ตอนส่งมอบ

แต่ถ้าไม่อยากยุ่ง ทักมาบอกผมก็ได้ครับ แก้เล็ก ๆ น้อย ๆ ผมทำให้
```

**แก้ได้กี่รอบ ทำไมจำกัด**
```
[Y รอบ] ครับ

เหตุผลที่จำกัดคืองานสองภาษา แก้หนึ่งรอบเท่ากับแก้สองภาษา
ถ้าไม่จำกัดเลย ราคานี้จะทำไม่ไหวจริง ๆ ครับ

แต่ในทางปฏิบัติ ถ้าแก้นิดหน่อยผมไม่นับครับ ที่นับคือรื้อโครงใหม่
```

**ขายของบนเว็บ ตัดบัตรได้ไหม**
```
ราคา 1,990 ยังไม่รวมระบบตะกร้าและตัดบัตรครับ

แต่ที่ทำได้และร้านส่วนใหญ่ใช้จริงกว่าคือ ให้ลูกค้าดูสินค้าและราคาบนเว็บ
แล้วกดปุ่มสั่งผ่านไลน์หรือแชทเลย ปิดการขายได้เหมือนกันและไม่มีค่าธรรมเนียม

แบบนี้พอไหวไหมครับ ถ้าอยากได้ระบบเต็มผมประเมินให้แยกได้
```

**ทำให้ติดหน้าแรก Google ได้ไหม**
```
ผมไม่สัญญาว่าติดหน้าแรกครับ ใครสัญญาแปลว่าเดาให้ฟัง

ที่ผมทำให้ได้จริงคือ ตั้งชื่อหน้าและคำอธิบายให้ครบทั้งสองภาษา
ส่งเว็บเข้า Google ให้ และเชื่อมกับ Google Maps
แปลว่าถ้ามีคนเสิร์ชชื่อร้านคุณ จะเจอเว็บครับ

ส่วนคำกว้าง ๆ เช่น "ร้านอาหารภูเก็ต" อันนั้นต้องลงทุนอีกแบบ
ซึ่งผมจะบอกตรง ๆ ว่าไม่รวมในราคานี้
```

**อยู่ต่างจังหวัด / ต่างประเทศ ทำได้ไหม**
```
ได้ครับ ทำผ่านแชทกับไลน์ทั้งหมด ไม่ต้องเจอกัน
ลูกค้าส่วนใหญ่ของผมก็คนละจังหวัดครับ

ส่งข้อมูลกับรูปมาทางแชทได้เลย
```

**จ่ายยังไง**
```
[มัดจำ]

โอนเข้าบัญชีธนาคารครับ ส่งสลิปมาในแชทได้เลย
ผมออกใบเสร็จให้ถ้าต้องการครับ
```

## §6 เจอข้อโต้แย้ง ตอบยังไง

**"แพงไป" / "เจ้าอื่น 990"**
```
เข้าใจครับ ผมอธิบายส่วนต่างให้นะครับ

เว็บ 990 ส่วนใหญ่คือภาษาเดียว ของผมคือสองภาษา
แปลว่าเนื้อหาทุกหน้าทำสองชุด และมีปุ่มสลับภาษาที่ใช้ได้จริงทั้งเว็บ

ถ้าลูกค้าคุณมีแต่คนไทย เว็บภาษาเดียวก็พอครับ ผมบอกตรง ๆ
แต่ถ้ามีต่างชาติแม้แต่ส่วนน้อย อันนี้คุ้มกว่าเยอะ

ร้านคุณมีลูกค้าต่างชาติบ้างไหมครับ
```
> จบด้วยคำถาม ไม่ใช่จบด้วยการป้องกันตัว
> **ห้ามลดราคาตรงนี้** ลดแล้วเพดานค่าโฆษณาหดตามทันที (`ads-playbook.md` §11)

**"ขอคิดดูก่อน"**
```
ได้เลยครับ ไม่ต้องรีบ

ระหว่างนี้ผมส่งตัวอย่างของธุรกิจแบบเดียวกับคุณไปให้ดูก่อนนะครับ 👉 [ตัวอย่าง]

ถ้ามีอะไรอยากถามเพิ่ม ทักมาได้ตลอดครับ
เดี๋ยวอีกสัก 2–3 วันผมทักมาถามอีกทีนะครับ เผื่อคิดออกแล้ว
```
> **ขออนุญาตตามกลับตั้งแต่ตอนนี้** ทำให้ข้อความตามกลับใน §7 ไม่ใช่การรบกวน

**"ขอปรึกษาหุ้นส่วน / ที่บ้านก่อน"**
```
ได้เลยครับ

เดี๋ยวผมสรุปสั้น ๆ ให้ส่งต่อได้เลยนะครับ
— เว็บ 2 ภาษา ไทย–อังกฤษ [n หน้า]
— 1,990 บาท เสร็จใน [X วัน] แก้ได้ [Y รอบ]
— ตัวอย่าง: [ตัวอย่าง]

ส่งอันนี้ให้เขาดูได้เลยครับ มีอะไรถามเพิ่มทักมาได้ตลอด
```

**"ตอนนี้ยังไม่พร้อม / ไว้ก่อน"**
```
ได้ครับ ไม่มีปัญหาเลย

ขอถามข้อเดียวนะครับ ที่ยังไม่พร้อมคือเรื่องงบ หรือเรื่องยังไม่มีรูป
กับเนื้อหาครับ

ถ้าเป็นเรื่องรูปกับเนื้อหา ผมช่วยแนะนำได้ว่าต้องเตรียมอะไรบ้าง
ไว้พร้อมแล้วค่อยเริ่มก็ได้ครับ
```
> คำตอบนี้มีค่ามาก เพราะแยก "ไม่มีเงิน" ออกจาก "ยังไม่ได้เตรียมของ"
> อย่างหลังคือลูกค้าที่กลับมาจริง ให้บันทึกไว้ใน JobDesk

## §7 เขาเงียบ ตามกลับยังไง

ตามกลับ 3 ครั้งแล้วหยุด มากกว่านั้นคือรบกวน และเสียเวลาที่เอาไปหาคนใหม่ได้

**+2 ชั่วโมง — ยังอยู่ในวันเดียวกัน**
```
เผื่อข้อความหายไปนะครับ 🙏
ยังสนใจอยู่ไหมครับ หรือมีอะไรที่ยังไม่ชัดให้ผมอธิบายเพิ่ม
```

**+1 วัน — ให้ของ ไม่ใช่ทวง**
```
สวัสดีครับ 🙏
ผมทำตัวอย่างหน้าเว็บของธุรกิจแบบเดียวกับคุณไว้ ลองดูได้ครับ 👉 [ตัวอย่าง]

ถ้าอยากได้แบบไหนเพิ่มบอกได้เลยครับ
```

**+3 วัน — ครั้งสุดท้าย และบอกว่าเป็นครั้งสุดท้าย**
```
รบกวนครั้งสุดท้ายนะครับ 🙏

ถ้าตอนนี้ยังไม่ใช่จังหวะ ไม่เป็นไรเลยครับ
ผมเก็บข้อมูลไว้ให้ ถ้าวันไหนพร้อมทักมาได้เลย ราคาเดิมครับ

ขอบคุณที่ทักมานะครับ
```

จากนั้น **หยุด** และบันทึกลง JobDesk เป็นคนทักที่ไม่ปิด พร้อมเหตุผล
ตัวหารของอัตราปิดการขายมาจากตรงนี้ ถ้าไม่บันทึก จะไม่มีวันรู้อัตราปิดจริง

> **ข้อจำกัดของ Messenger:** ตอบกลับได้แน่นอนภายใน 24 ชั่วโมงหลังเขาทักล่าสุด
> หลังจากนั้นการส่งข้อความมีข้อจำกัดของ Meta อยู่ — พิมพ์ตอบเองจากกล่องข้อความ
> ยังส่งได้อีกระยะ แต่อย่าวางแผนตามกลับยาวกว่าไม่กี่วัน
> **ข้อความ +2 ชั่วโมงจึงสำคัญที่สุดในสามข้อ** เพราะเป็นข้อเดียวที่ส่งได้ชัวร์

## §8 ข้อความเมื่อไม่อยู่

ตั้งเวลาให้ตรงกับที่ตอบได้จริง ไม่ใช่ตั้งกว้างไว้ก่อน

```
สวัสดีครับ ขอบคุณที่ทักมานะครับ 🙏
ตอนนี้นอกเวลาทำงาน ผมจะตอบกลับให้ภายใน [เวลาที่ตอบได้จริง] ครับ

ระหว่างนี้ทิ้งไว้ได้เลยครับว่าทำธุรกิจอะไร
เดี๋ยวผมส่งตัวอย่างเว็บที่ใกล้เคียงไปให้ดูพร้อมกับคำตอบเลย
```

## §9 บันทึกลง JobDesk ทุกคน ไม่ใช่เฉพาะคนที่ซื้อ

ทุกคนที่ทักมาต้องกลายเป็นแถวหนึ่งแถวในระบบ พร้อมแคมเปญที่พามาและเหตุผลที่ไม่ซื้อ

**เหตุผลที่ไม่ซื้อ คือข้อมูลที่แพงที่สุดที่จะได้จากแชท**

| ถ้าเหตุผลไหนขึ้นมาเกินครึ่ง | แปลว่า | แก้ที่ไหน |
|---|---|---|
| แพงไป | โฆษณาดึงคนผิดกลุ่ม ไม่ใช่ราคาผิด | ทำให้โฆษณาพูดราคาและคำว่าสองภาษาชัดขึ้น |
| ไม่ต้องการสองภาษา | ยิงกว้างเกินไป | ลองกลุ่มจังหวัดท่องเที่ยว (`ads-playbook.md` §3.2) |
| ยังไม่มีรูป/เนื้อหา | ไม่ใช่คนไม่ซื้อ คือคนที่ยังไม่พร้อม | ตามกลับเดือนหน้า |
| เงียบหายไปเฉย ๆ | ข้อความแรกยังไม่ดีพอ หรือตอบช้า | §2 และความเร็ว 5 นาที |

## §10 ทำอะไรก่อนหลัง

1. เติมช่องว่าง 7 ช่องใน §0 — ใช้เวลา 10 นาที และทุกอย่างที่เหลือขึ้นกับข้อนี้
2. วางข้อความ §2 เป็น **ตอบกลับทันที** ในเพจ
3. วาง 4 ข้อใน §5 เป็น **คำถามที่พบบ่อย**
4. วาง §3, §6, §7 เป็น **ข้อความที่บันทึกไว้** — ตั้งชื่อให้หาเจอเร็ว
5. ตั้ง **ข้อความเมื่อไม่อยู่** ตาม §8
6. ทดสอบด้วยตัวเอง — ทักเข้าเพจตัวเองจากอีกบัญชี แล้วเดินตามบันไดจนจบ

**ทำครบ 6 ข้อนี้แล้วค่อยเปิดโฆษณา** (`ads-playbook.md` §12)
คนที่ทักเข้ามาตอนที่ยังไม่มีข้อความรออยู่ คือเงินที่จ่ายไปซื้อบทสนทนาที่แพ้แล้ว
