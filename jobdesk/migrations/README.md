# Migrations

`schema.sql` คือโครงเต็มสำหรับการติดตั้งใหม่ ส่วนโฟลเดอร์นี้คือการเปลี่ยนแปลง
ที่ตามมาทีหลัง สำหรับฐานข้อมูลที่มีข้อมูลจริงอยู่แล้วและลบทิ้งไม่ได้

```bash
cd app
npm run db -- migrate     # รันเฉพาะไฟล์ที่ยังไม่เคยรัน
npm run db -- init        # ติดตั้งใหม่: schema.sql แล้วตามด้วย migration ทั้งหมด
```

ไฟล์ที่รันไปแล้วถูกบันทึกไว้ในตาราง `schema_migrations` จึงรันซ้ำได้โดยไม่พัง

**กฎ:** ทุกครั้งที่แก้ `schema.sql` ต้องเขียน migration คู่กันเสมอ
มิฉะนั้นเครื่องที่ติดตั้งไปแล้วจะตามไม่ทัน
