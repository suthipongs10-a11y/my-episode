## §1 ชื่อคลิป — 3 รูปแบบ

### 🅰️ แบบ 1 — คำถามตรง ๆ · กินการค้นหา

```
ทำไมกลางคืนท้องฟ้าถึงมืด? คำตอบไม่ใช่ "ดวงอาทิตย์ตก" — และมันบอกอายุของจักรวาล
```

### 🅱️ แบบ 2 — ข้ออ้างที่ไม่น่าเป็นไปได้ · กินการกดจากฟีด **(ใช้ตัวนี้)**

```
ถ้าจักรวาลไม่มีที่สิ้นสุด ฟ้ากลางคืนต้องสว่างเท่าผิวดวงอาทิตย์ — แล้วทำไมมันมืด
```

บรรทัดนี้ทำงานเพราะมันเป็น**ข้อสรุปที่ฟังดูบ้า แต่ตามมาจากสมมติฐานที่ทุกคนยอมรับ**
คนที่กดเข้ามาเพราะอยากรู้ว่าตรรกะพังตรงไหน คือคนที่จะดูจนจบ

### 🅲 แบบ 3 — หมัดฮุกนำ · สำหรับคนที่รู้เรื่องนี้อยู่แล้ว

```
ฟ้ากลางคืนสว่างทั้งผืนอยู่แล้ว ที่ 2.725 เคลวิน — เราแค่มองด้วยตาไม่เห็น
```

```

ลองตั้งสมมติฐานสามข้อ: จักรวาลกว้างไม่มีที่สิ้นสุด เก่าแก่ไม่มีจุดเริ่มต้น และมีดาวกระจายอยู่ทั่วอย่างสม่ำเสมอ
```
